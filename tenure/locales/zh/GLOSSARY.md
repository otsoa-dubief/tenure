# Tenure — glossaire zh (简体中文)

Termes Hermes repris de `apps/desktop/src/i18n/zh.ts` et `locales/zh.yaml`.

- tier → 级别 (codes T1 T2 T3 et CAP inchangés)
- earned autonomy → 已赢得的自主权 (verbe : 赢得自主权)
- action type → 操作类型
- action → 操作
- agent → 智能体 (comme Hermes Desktop)
- spot check / spot-checked → 抽查 / 接受抽查 ; « 1 in k » → 每 k 个抽查 1 个
- fault → 失误 ; error → 错误
- flag → 标记 (标记为失误)
- revoke → 收回 (收回自主权)
- undo → 撤销 (Hermes)
- preset → 预设 ; careful / balanced / fast → 谨慎 / 平衡 / 快速 (libellés seulement ; la commande garde `hermes tenure setup balanced`)
- custom (preset) → 自定义
- passport → 护照
- ledger → 账本 ; hash chain → 哈希链 ; head → 头部
- provisional → 暂定
- carried over → 继承 ; kept / reset / vetoed → 保留 / 重置 / 否决
- stakes low / medium / high → 低风险 / 中风险 / 高风险 (seul : 低 / 中 / 高)
- risk (taux accepté) → 风险率 ; accepted risk → 可接受风险
- capped → 受限 (« capped: always asks » → 受限：始终询问)
- clean run / in a row / series → 连续成功 / 连续 / 连续记录
- trial → 考察期 ; suspended → 已暂停
- benchmark (your benchmark) → 你的基准
- public score / public measure → 公开分数 / 公开测评
- 95% range → 95% 区间 ; fault rate → 失误率
- asks first → 先询问
- acts, then tells you / notifies → 先执行后告知
- acts on its own → 自主执行
- strict mode → 严格模式
- evidence → 证据 ; verified → 已验证
- guarantee → 保证
- session → 会话 ; profile → 配置文件 ; provider → 提供方 ; model → 模型 ; settings → 设置
- approve / Run / Reject / Allow this session / Always allow → 批准 / 运行 / 拒绝 / 允许本会话 / 始终允许
- dashboard → 仪表盘 ; redacted → 已脱敏
- Libellés d'interface cités dans une phrase : 「…」 ; ponctuation pleine chasse ; espace entre chinois et chiffres/latin (style Hermes zh).
