# clearance is installed

By **Otsoa Dubief** · https://github.com/otsoa-dubief/clearance

1. Restart a running gateway: `hermes gateway restart`
2. Pick your risk: `hermes clearance setup` (default: balanced)
3. Work as usual. Every action that changes something asks until its type has earned autonomy.
   `hermes clearance` shows where each type stands; the dashboard has a Clearance tab.

Needs `approvals.mode: manual` to learn. How it decides: `hermes clearance explain`.
